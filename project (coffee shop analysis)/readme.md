Coffee Shop Sales Analysis

Objective
Analyze coffee shop sales to understand revenue, transaction value, daily sales patterns, and monthly performance using Excel.

Dataset
- Dataset: Maven Coffee Shop Sales
- Period: January–June 2023
- Records: 149,116 transactions
- Fields include transaction date, quantity, unit price, product category, and product details.

Analysis Completed
- Total sales revenue
- Total transactions
- Average transaction value
- Daily sales analysis
- Monthly sales analysis
- Month-over-month growth calculations

Excel Skills Practised
- SUMPRODUCT
- COUNTA
- SUMIFS
- IFERROR
- Date-based calculations
- Month-over-month growth calculations

Limitations
The dataset covers January–June 2023 only, so year-over-year growth cannot be calculated without prior-year data. The XLOOKUP practice exercise was skipped and is not included among completed tasks.

Validation
KPI totals and monthly sales totals should be checked against the source data before final submission.

AI Use
AI assistance was used to troubleshoot Excel formulas and structure the analysis. Formulas and outputs were checked manually where possible.
